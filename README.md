# Speech after a tongue-tie release: a first-month practice log

A first-month speech-practice log after a tongue-tie release, with ASHA, MedlinePlus and NIDCD sources.

This is a free, standalone mini-resource. The live HTML page is intended to be served from:

- Render: `https://tongue-tie-speech-practice-log.onrender.com/`
- GitHub Pages: `https://ahmetalkan.github.io/tongue-tie-speech-practice-log/`

It cites public pages on [frenectomyguide.com](https://frenectomyguide.com/) and official reference sources listed at the bottom of the page. Nothing here is a substitute for advice from a qualified professional.
